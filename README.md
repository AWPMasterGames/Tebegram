# Tebegram
Наш проект — это кроссплатформенный мессенджер, вдохновленный Telegram. Основной функционал включает обмен медиафайлами и документами и много чего другого.

## Что нового в релизе 2.0.0

- групповые чаты: создание, сообщения, удаление группы владельцем (не владельцу теперь честно сообщается о нехватке прав);
- статусы сообщений: часики → галочка (на сервере) → две галочки (прочитано), красный «!» при ошибке; индикатор загрузки файлов;
- локальный кэш фото и видео на диске, очистка кэша в настройках;
- отправка файлов любого типа, единый лимит 16 МБ (потолок туннеля);
- выбор сервера: «main» (адрес из Adress.txt) или «Другой» (свой адрес), выбор сохраняется между запусками;
- звонки: «Соединяем…» до ответа, индикатор микрофона СОБЕСЕДНИКА, входящий звонок выносится на передний план по центру экрана;
- светлая тема стала серее, точки на фоне чата в обеих темах;
- веб-клиент (docs/) и установщик Inno Setup с автообновлением.
