Обновление Tebegram: исправление багов, новый установщик, веб-приложение для телефона и улучшения дизайна

=== СЕРВЕР (Tebegram-server) ===
- Исправлено: каждое сообщение создавало новый чат — теперь сервер ищет существующий чат между участниками.
- Исправлено: очистка пустых голосовых комнат не работала никогда (перепутан порядок вычитания дат).
- Исправлены падения сервера: невалидный userId в /Chat/ws и /Voice/ws, повторный DeclineCall,
  несуществующий пользователь в /UserName, /avatars, /messages, /Contact.
- Исправлено: аватарки загружались в папку avatars, а искались в Data/avatars — не находились никогда.
- Исправлено: автосохранение сдвигало время сообщений на +3 часа и меняло его формат.
- Исправлено: автосохранение падало при одновременных запросах (добавлены снимки коллекций).
- Исправлено: мёртвые сокеты копились в списке сессий навсегда; голосовые пакеты пересылались
  с мусором в хвосте буфера; длинные сообщения (больше 4 КБ) разрезались на части;
  символ-разделитель в тексте сообщения терялся.
- Голосовые пакеты теперь отправляются последовательно (два параллельных SendAsync роняли сокет).
- Регистрация: айди берётся как максимальный+1 (раньше после удаления пользователей айди дублировались),
  добавлена проверка занятости имени пользователя.
- Добавлен CORS и раздача веб-приложения по адресу /app.

=== КЛИЕНТ (Tebegram-client, WPF) ===
- Исправлено: чат не мог подключиться через devtunnel (https подменялся на ws вместо wss).
- Добавлено автопереподключение WebSocket каждые 3 секунды при обрыве связи.
- Исправлено: кнопка «Выйти из аккаунта» убивала всё приложение (Process.Kill в закрытии окна).
- Исправлено: время сообщений было в 12-часовом формате (13:05 отправлялось как 01:05).
- Данные входа и настройки перенесены в AppData (в Program Files запись запрещена — приложение падало
  после установки). Старые файлы мигрируют автоматически.
- Исправлено: выбранное устройство записи игнорировалось (индекс всегда ставился в 1).
- Исправлено: поток звонка съедал целое ядро процессора (цикл без задержки) и показывал
  MessageBox при каждом переключении микрофона.
- Исправлено: логгер спал 100 мс на каждой записи; входящие сообщения от нового контакта
  записывались с чужим именем отправителя; длинные сообщения обрезались (буфер 1 КБ).
- Добавлена проверка обновлений: клиент сверяет версию с version.txt на GitHub и предлагает
  скачать новую версию со страницы релизов (Classes/UpdateChecker.cs).

=== ДИЗАЙН КЛИЕНТА ===
- Свои сообщения теперь справа с акцентным цветом, чужие слева (как во всех мессенджерах).
- Автопрокрутка к новому сообщению.
- Заглушка «Выберите, кому хотите написать», пока чат не открыт.
- Поправлено поле поиска (размер шрифта, выравнивание).

=== УСТАНОВЩИК (Installer) ===
- Создан классический setup.exe на Inno Setup со ВСТРОЕННЫМ .NET — пользователю ничего не нужно
  доустанавливать. Ставится без прав администратора.
- Сборка одной кнопкой: Installer\build-installer.bat (публикация + компиляция).
- Настроена автосборка на GitHub: пуш тега вида v1.0.4 — установщик собирается сам
  и прикладывается к релизу (.github/workflows/build-installer.yml).
- Объяснение «пропадающих файлов»: папки bin/obj игнорируются гитом (это правильно),
  собранные установщики выкладываются в GitHub Releases, а не в репозиторий (Installer\README.md).
- Установщик — только Inno Setup (.exe); старый WiX-проект (.msi) удалён.

=== ВЕБ-ПРИЛОЖЕНИЕ ДЛЯ ТЕЛЕФОНА (папка docs) ===
- Полноценный PWA-клиент на чистом HTML/CSS/JS: вход и регистрация, список чатов с превью
  последнего сообщения, переписка в реальном времени через WebSocket, отправка файлов, аватарки.
- Ставится на главный экран iPhone/Android как настоящее приложение: полный экран,
  своя иконка, без адресной строки (манифест + service worker + безопасные зоны под «чёлку»).
- Тёмная и светлая тема автоматически, дизайн в палитре десктопного клиента.
- Адрес сервера подтягивает сам из Adress.txt на GitHub (как десктопный клиент).
- Раздаётся сервером по /app и готов к публикации на GitHub Pages (инструкция в docs/README.md).
- Голосовые звонки работают (см. раздел «ГОЛОСОВАЯ СВЯЗЬ»).

=== ПАПКИ КОНТАКТОВ ===
- Папки теперь сохраняются на сервере и не теряются при перезапуске:
  новые эндпоинты GET/PUT /Folders/{userId}.
- Десктоп: при входе папки загружаются с сервера, после закрытия окна
  редактирования папок — сохраняются на сервер автоматически.
- Веб: папки отображаются как фильтры-чипсы над списком чатов.

=== НАСТРОЙКИ (десктоп) ===
- Добавлена смена аватара (кнопка под аватаром, загрузка на сервер).
- Добавлена секция «Приложение»: версия и кнопка «Проверить обновления».
- Убраны подвисания (лишние задержки в коде окна).

=== ДИЗАЙН-ПРОХОД ПО ЧЕКЛИСТУ UI/UX ===
- В вебе эмодзи-иконки заменены на SVG (те же иконки, что в десктопном клиенте).
- Сенсорные цели доведены до 44pt (стандарт Apple).
- Добавлены aria-метки для кнопок, видимый фокус с клавиатуры,
  поддержка системной настройки «уменьшить движение».

=== ГОЛОСОВАЯ СВЯЗЬ (реализовано) ===
- Единый формат звука на всех платформах: PCM 16 бит, 48 кГц, моно.
- ПК: NAudio переведён на 48 кГц (было нестандартных 20480 Гц).
- Веб: полноценные звонки через Web Audio API (AudioWorklet) — захват микрофона,
  отправка/приём PCM по WebSocket, экран входящего/исходящего звонка, микрофон,
  таймер разговора, завершение. Файл docs/voice-worklet.js.
- Проверено: пакеты PCM проходят через сервер точно, без искажений — значит
  ПК, веб и будущий Android совместимы между собой (общий формат байт).
- План дальнейшего развития (Opus, WebRTC) — в VOICE-PLAN.md.

=== ИЗБРАННОЕ (чат с самим собой, как в Telegram) ===
- У каждого пользователя автоматически появляется «Избранное» — чат с собой,
  всегда первым в списке, со своей иконкой-закладкой.
- Исправлено дублирование: сообщение самому себе сохраняется и показывается
  один раз (раньше дублировалось).

=== ДАТЫ СООБЩЕНИЙ (как в Telegram) ===
- Между сообщениями разных дней — плашка-разделитель: Сегодня / Вчера /
  4 июля / 4 июля 2025.
- В пузыре показывается только время (ЧЧ:ММ), полная дата хранится внутри.
- Работает и в десктопе (группировка), и в вебе.

=== УДАЛЕНИЕ СООБЩЕНИЙ ===
- Можно удалить сообщение «у себя» или «у всех» (у себя и у собеседника).
- Десктоп: правый клик по сообщению. Веб: долгое нажатие / правый клик.
- При «удалить у всех» сообщение исчезает и у собеседника в реальном времени.

=== БАЗА ДАННЫХ (пояснение) ===
- Полноценной БД пока нет: данные лежат в одном JSON-файле
  Tebegram-server/Data/Users.json, который целиком перезаписывается каждые
  10 секунд. Переход на SQLite/LiteDB остаётся в списке улучшений.

=== ИНДИКАТОР СВЯЗИ (окна входа и регистрации) ===
- На оба окна добавлена неприметная точка-индикатор соединения с сервером:
  зелёная — сервер на связи, серая — идёт проверка, красная — нет ответа за 3 секунды.
- Проверка повторяется каждые 5 секунд; при закрытии окна останавливается.
- Реализация: ServerData.PingAsync() (запрос /Test с таймаутом 3 с) + монитор в MainWindow.

=== ПРОЧЕЕ ===
- version.txt в корне — по нему клиенты узнают о новых версиях.
- Файл Adress.override.txt рядом с exe позволяет переопределить адрес сервера для тестов
  (в установщик не попадает).
- Адрес сервера переключён на туннель DrunkMan (https://d6qdbhpn-5000.euw.devtunnels.ms).
- Клиенты теперь проверяют несколько путей к Adress.txt (ветка main-dev-Test — временно,
  для проверки; затем main в новой и старой раскладке).
