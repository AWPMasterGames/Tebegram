# Tebegram Web (PWA)

Мобильный веб-клиент Tebegram. Чистый HTML/CSS/JS, без сборки.
Работает с тем же сервером и протоколом, что и десктопный клиент,
адрес сервера подтягивает из `Adress.txt` на GitHub (как десктоп).

## Как включить GitHub Pages (один раз)

1. Смержи эту папку в ветку `main`.
2. На GitHub: **Settings → Pages**.
3. В «Build and deployment»: Source = **Deploy from a branch**,
   Branch = **main**, папка = **/docs** → Save.
4. Через пару минут приложение будет доступно по адресу:
   `https://awpmastergames.github.io/Tebegram/`

## Как пользователю установить «приложение» на iPhone

1. Открыть адрес в **Safari**.
2. Нажать кнопку «Поделиться» (квадрат со стрелкой).
3. Выбрать «**На экран “Домой”**».
4. На главном экране появится иконка Tebegram — открывается на весь экран,
   без адресной строки, неотличимо от нативного приложения.

На Android Chrome сам предложит «Установить приложение».

## Альтернативный адрес

Сервер тоже раздаёт этот веб-клиент по пути `/app`
(например `https://<твой-devtunnel>/app/`) — удобно для проверки,
но для ярлыков лучше GitHub Pages: адрес никогда не меняется.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | разметка всех экранов (вход, чаты, переписка, настройки) |
| `styles.css` | стили в духе iOS, тёмная/светлая тема автоматически |
| `app.js` | протокол Tebegram, WebSocket с автопереподключением, UI |
| `sw.js` | service worker — оффлайн-оболочка и мгновенный запуск |
| `manifest.webmanifest` | манифест PWA (имя, иконки, standalone-режим) |
| `icons/` | иконки, сгенерированы из Icon.ico клиента |

Голосовые звонки: серверный протокол уже обёрнут в объект `Voice` в `app.js`
(создание комнаты, входящие, WebSocket-адрес). Осталось реализовать захват и
воспроизведение звука через Web Audio API — включается флагом `Voice.ENABLED`.
