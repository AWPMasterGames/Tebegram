# Tebegram Web (PWA)

Веб-клиент Tebegram. Чистый HTML, CSS и JavaScript, без этапа сборки.
Работает с тем же сервером и протоколом, что и десктопное приложение.
Адрес сервера читается из `Adress.txt` в корне репозитория, как и в десктопном клиенте.

## Как включить GitHub Pages

Выполняется один раз.

1. Слить эту папку в ветку `main`.
2. Открыть на GitHub: Settings, далее Pages.
3. В разделе «Build and deployment» выбрать Source = Deploy from a branch,
   Branch = `main`, папка = `/docs`, нажать Save.
4. Через несколько минут приложение станет доступно по адресу
   `https://awpmastergames.github.io/Tebegram/`

## Установка на телефон

Веб-клиент устанавливается как обычное приложение: с иконкой на рабочем столе,
в полноэкранном режиме и без адресной строки браузера.

### Android

Способ 1, автоматический. Chrome сам показывает предложение «Установить приложение»
внизу экрана. Достаточно нажать «Установить».

Способ 2, вручную, если предложение не появилось или было закрыто:

1. Открыть адрес в Chrome.
2. Нажать кнопку меню: три точки в правом верхнем углу.
3. Выбрать пункт «Установить приложение». В некоторых версиях Chrome и в
   других браузерах на движке Chromium пункт называется «Добавить на главный экран».
4. Подтвердить установку.

Если пункта нет совсем, проверьте два условия: адрес открыт по HTTPS, а не по HTTP
или IP-адресу, и страница загрузилась полностью. Без выполнения обоих условий
браузер установку не предлагает.

В Samsung Internet путь отличается: меню, затем «Добавить страницу», затем
«Главный экран».

### iPhone и iPad

Установка возможна только через Safari. В Chrome на iOS этой функции нет.

1. Открыть адрес в Safari.
2. Нажать кнопку «Поделиться»: квадрат со стрелкой вверх.
3. Пролистать список и выбрать «На экран „Домой“».
4. Подтвердить кнопкой «Добавить».

## Звонки требуют HTTPS

Доступ к микрофону браузер разрешает только в защищённом контексте. Исключение
сделано единственно для `localhost`. По адресу вида `http://192.168.0.5:5000`
объект `navigator.mediaDevices` отсутствует, поэтому звонок не начнётся, причём
браузер не покажет никакого сообщения.

Открывайте приложение по адресу с `https://`: через GitHub Pages либо по ссылке
туннеля. Оба варианта дают защищённый контекст, и звонки работают.

### Звонки в локальной сети без туннеля

Сервер умеет слушать дополнительный порт по HTTPS. Включается переменными
окружения:

```
HttpsPort=5001
HttpsCertPath=<путь к .pfx>
HttpsCertPassword=<пароль>
```

Без `HttpsPort` привязка прежняя, только HTTP. Если путь к сертификату не задан,
берётся сертификат `dotnet dev-certs`, но он выписан на `localhost`, поэтому по
IP-адресу браузер сообщит о несовпадении имени.

Чтобы предупреждения не было, сертификат должен содержать нужный адрес в поле
`subjectAltName` и быть установлен на устройстве как доверенный.

## Альтернативный адрес

Сервер раздаёт этот же веб-клиент по пути `/app`, например
`https://<адрес-туннеля>/app/`. Такой вариант удобен для проверки, но для ярлыка
на телефоне лучше GitHub Pages: его адрес не меняется при перезапуске сервера.

## Состав папки

| Файл | Назначение |
|---|---|
| `index.html` | разметка всех экранов: вход, список чатов, переписка, настройки |
| `styles.css` | стили, светлая и тёмная темы переключаются автоматически |
| `app.js` | протокол Tebegram, WebSocket с автопереподключением, интерфейс |
| `sw.js` | service worker: офлайн-оболочка и быстрый запуск |
| `manifest.webmanifest` | манифест PWA: имя, иконки, полноэкранный режим |
| `icons/` | иконки, созданы из Icon.ico десктопного клиента |
